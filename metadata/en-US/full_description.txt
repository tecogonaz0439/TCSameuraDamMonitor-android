TCSameuraDamMonitor fetches dam data published by the Ministry of Land, Infrastructure, Transport and Tourism (MLIT) Hydrological and Water Quality Database and displays storage rates and related data for 125 dams in Japan, including Sameura Dam.

Features:
* Real-time data — fetches and stores real-time data, showing storage rate, storage volume, inflow, discharge and basin-average rainfall
* Storage rate messages — displays status and messages based on the storage rate, customizable
* Historical data — fetches and stores past data for any period, with offline search (Sameura Dam only)
* Interactive graphs — graphs for real-time and historical data (rainfall/storage rate, storage volume/inflow/discharge)
* Home screen widget — check the real-time storage rate and message at a glance
* Auto update and notifications — background real-time data fetching and storage change notifications

This app only uses official MLIT data sources (directly or via a cache server) and contains no ads, trackers or analytics.
