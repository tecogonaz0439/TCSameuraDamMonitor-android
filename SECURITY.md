# Security Policy

**Last updated: 2026-06-24**

## Supported Versions

Security updates are provided only for the latest release.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not create a public Issue, but report it by email to [tecogonaz@kusugami-lab.net](mailto:tecogonaz@kusugami-lab.net). I will respond as quickly as possible.
